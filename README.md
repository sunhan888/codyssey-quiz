# 🎯 코디세이 OT 퀴즈 게임

## 프로젝트 개요

터미널에서 실행하는 Python 퀴즈 게임입니다.
메뉴에서 번호를 골라 퀴즈를 풀고, 새 퀴즈를 추가하고, 목록과 최고 점수를 확인할 수 있습니다.
추가한 퀴즈와 최고 점수는 `state.json` 파일에 저장되어 프로그램을 종료한 뒤 다시 실행해도 유지됩니다.

- 언어: Python 3.10 이상 (외부 라이브러리 없이 표준 라이브러리만 사용)
- 구조: `Quiz`, `QuizGame` 두 클래스로 역할 분리

## 퀴즈 주제와 선정 이유

**주제: 코디세이 AI 올인원 제1기 입학연수과정 오리엔테이션(OT) 내용**

입학연수과정에는 장학금 기준(출입 시간, 동료평가 횟수), 본과정 선발 기준, 동료평가 규칙처럼
과정 내내 꼭 기억해야 하는 숫자와 규칙이 많습니다.
OT 자료를 한 번 읽고 끝내지 않고, 퀴즈로 반복해서 떠올리며 자연스럽게 익히기 위해 이 주제를 골랐습니다.
함께 공부하는 동료 교육생도 이 게임으로 과정 규칙을 점검할 수 있습니다.

## 실행 방법

```bash
git clone https://github.com/sunhan888/codyssey-quiz.git
cd codyssey-quiz
python main.py
```

## 기능 목록

| 메뉴 | 기능 | 설명 |
|---|---|---|
| 1 | 퀴즈 풀기 | 저장된 퀴즈를 순서대로 출제하고, 정답/오답과 최종 점수(100점 만점)를 보여줍니다. |
| 2 | 퀴즈 추가 | 문제, 선택지 4개, 정답 번호를 입력받아 새 퀴즈를 등록하고 바로 파일에 저장합니다. |
| 3 | 퀴즈 목록 | 등록된 퀴즈의 문제를 번호와 함께 보여줍니다. |
| 4 | 점수 확인 | 최고 점수를 보여줍니다. 퀴즈를 풀 때마다 최고 점수와 비교해 갱신합니다. |
| 5 | 종료 | 데이터를 저장하고 프로그램을 종료합니다. |

### 입력 및 예외 처리

- 입력 앞뒤 공백은 제거한 뒤 처리합니다.
- 빈 입력, 숫자가 아닌 입력(예: `abc`), 허용 범위 밖 숫자(예: 메뉴 `9`, 정답 `0`)는 안내 메시지를 보여주고 다시 입력받습니다.
- `Ctrl+C`(KeyboardInterrupt)나 입력 종료(EOFError)가 발생하면 데이터를 저장하고 안전하게 종료합니다.
- 퀴즈가 하나도 없거나, 아직 퀴즈를 풀지 않은 경우에도 안내 메시지를 보여줍니다.

## 파일 구조

```
codyssey-quiz/
├── main.py        # 실행 시작점: QuizGame을 만들고 실행
├── quiz_game.py   # QuizGame 클래스: 메뉴, 게임 진행, 파일 저장/불러오기, 입력 검증 함수, 기본 퀴즈
├── quiz.py        # Quiz 클래스: 퀴즈 한 문제(출력, 정답 확인, 딕셔너리 변환)
├── state.json     # 실행 시 자동 생성되는 데이터 파일 (Git에는 올리지 않음)
├── .gitignore
└── README.md
```

## 데이터 파일 설명 (state.json)

- **경로**: 프로젝트 루트의 `state.json`
- **역할**: 퀴즈 목록과 최고 점수를 저장해, 프로그램을 다시 실행해도 데이터가 유지되게 합니다.
- **인코딩**: UTF-8 (한글이 그대로 보이도록 저장)
- **저장 시점**: 퀴즈를 추가했을 때, 최고 점수가 갱신됐을 때, 프로그램을 종료할 때

### 스키마

```json
{
    "quizzes": [
        {
            "question": "입학연수과정 장학금 금액은?",
            "choices": ["50만원", "80만원", "100만원", "150만원"],
            "answer": 3
        }
    ],
    "best_score": 75
}
```

| 키 | 자료형 | 설명 |
|---|---|---|
| `quizzes` | list | 퀴즈 목록 |
| `quizzes[].question` | str | 문제 |
| `quizzes[].choices` | list (str 4개) | 선택지 |
| `quizzes[].answer` | int (1~4) | 정답 번호 |
| `best_score` | int 또는 null | 최고 점수(100점 만점). 아직 풀지 않았으면 `null` |

### 파일이 없거나 손상된 경우

- **파일이 없으면** (첫 실행): 기본 퀴즈 8문제로 시작합니다.
- **파일이 손상되었으면** (JSON 형식 오류, 필드 누락, 잘못된 값): 안내 메시지를 보여주고 기본 퀴즈 데이터로 복구한 뒤 다시 저장합니다.
- `state.json`은 플레이할 때마다 바뀌는 데이터이므로 `.gitignore`에 추가해 Git으로 관리하지 않습니다.
